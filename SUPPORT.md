# Support

Pulse Bridge for Tibber is a community project maintained in spare time. There is no guaranteed response time.

| You have … | Go to |
|---|---|
| a setup or usage question | [Troubleshooting & FAQ](docs/troubleshooting.md), then [GitHub Discussions](https://github.com/Xander2980/pulse-bridge/discussions) |
| found a bug | [Problem report](https://github.com/Xander2980/pulse-bridge/issues/new?template=1-report-an-issue.yaml) (with debug log) |
| a meter protocol that is not supported | [Protocol report](https://github.com/Xander2980/pulse-bridge/issues/new?template=3-unsupported-type.yaml) |
| an idea for a feature | [Feature request](https://github.com/Xander2980/pulse-bridge/issues/new?template=2-feature-request.yaml) |
| a security problem | see [SECURITY.md](SECURITY.md) – do not open a public issue |

This project is not affiliated with Tibber. Questions about your Tibber contract, the Tibber app or the cloud service go to Tibber support. Questions about the original `tibber_local` integration go to [its repository](https://github.com/marq24/ha-tibber-pulse-local).
